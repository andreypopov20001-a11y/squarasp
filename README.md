# Студенческая платформа БФ СГЮА

Расписание всех групп СПО (Юриспруденция 40.02.04 и Правоохранительная деятельность 40.02.02, 9 и 11 кл), чаты университета, потока и группы, советы о преподавателях и доска идей. Высшее образование: «скоро».

## 1. Выложить сайт (как раньше)
1. Новый репозиторий на GitHub, загрузи **всё содержимое папки** (включая скрытую `.github`).
2. **Settings → Pages → Source: GitHub Actions**.
3. **Actions → «Обновить расписание и опубликовать сайт» → Run workflow**.

Каждые 3 часа GitHub сам скачивает PDF с balakovo.ssla.ru (эту и следующую неделю), разбирает их и обновляет сайт. Список PDF — `scripts/catalog.py`. Новый курс или программа = одна строка. Группы определяются по имени файла (`БФЮРОО26-010203` → группы 01, 02, 03). Преподаватели собираются из самих расписаний.

Расписание работает **без регистрации**. Регистрация нужна только для чатов, советов и идей.

## 2. Подключить чаты (Supabase, бесплатно)
1. Зарегистрируйся на supabase.com → **New project**.
2. **SQL Editor** → вставь весь `schema.sql` → **Run**, затем так же весь `schema_v2.sql` → **Run** (календарь, опросы, объявления, материалы, бан, удаление аккаунта).
3. **Project Settings → API**: скопируй `Project URL` и ключ `anon public` в `config.js`. Ключ `service_role` никуда не вставляй.
4. **Authentication → URL Configuration**: в *Site URL* укажи адрес сайта (`https://НИК.github.io/schedule/`). Нужно для писем подтверждения и сброса пароля.
5. Первый админ: сначала зарегистрируйся на сайте, затем в SQL Editor: `update profiles set role='admin' where id=(select id from auth.users where email='ТВОЯ@ПОЧТА');` (так же можно назначать `moderator`). Через сайт роль поменять нельзя.

Письма Supabase на бесплатном тарифе ограничены по количеству. Для большого потока подключи свой SMTP (Authentication → SMTP).

## Как это устроено
- **Комнаты:** `univ` (все), `stream:<специальность-база-курс>` (поток), `group:<группа>` (группа). Доступ проверяет база (RLS), а не кнопки на сайте.
- **Ограничение:** принадлежность к группе и потоку студент указывает сам, проверки по зачётке нет. Модераторы могут удалять сообщения.
- Антиспам: до 15 публикаций в минуту с аккаунта. Жалобы (⚑) попадают в таблицу `reports`, читать её могут только модераторы.
- Почта никому не показывается.

## Админка и модерация
В «Ещё → 🛡 Админка» (видна модераторам и админам): статистика, жалобы (удалить публикацию / забанить автора / отклонить), последние публикации, список пользователей с баном; админ ещё выдаёт и снимает роль модератора. Забаненный не может писать, создавать события и голосовать. Модераторы видят все комнаты и могут публиковать объявления и общие дедлайны.

## Что пока не сделано
Push-уведомления (нужен внешний сервис), загрузка файлов (материалы пока только ссылками), месячная сетка календаря (сейчас список + экспорт .ics), счётчик непрочитанного.

## Локальный запуск
`pip install -r requirements.txt && python scripts/update_schedule.py && python -m http.server`
